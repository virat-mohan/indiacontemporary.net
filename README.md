# India Contemporary

Frontend for indiacontemporary.net — an art marketplace sourcing original work
from India's contemporary artists and selling to collectors across Europe.

Design system: warm neutral gallery palette, Cormorant Garamond (serif) +
Outfit (sans-serif), minimalist product-grid layout.

## Stack

React + Vite + Tailwind CSS + React Router. Content currently comes from
static mock data in `src/data/` — no backend yet.

## Develop

```
npm install
npm run dev
```
